Selected projects

AI SOC: ML-powered network attack detection

A team project with Merna Mohamed (AI and data science) that simulates a SOC workflow from raw network data to the analyst’s decision. It detects DDoS, brute force, port scans and botnet beaconing: a LightGBM classifier handles known attacks and an Isolation Forest catches unusual traffic no class explains.

Every alert is explained with TreeSHAP and mapped to MITRE ATT&CK. In our test run, 7,177 alerts were grouped into 43 risk-scored incidents. The Streamlit dashboard has a live threat level, a connection graph, attack replay, response playbooks, downloadable incident reports and an IOC blocklist export.

Results are on synthetic data, so scores are optimistic. Next step: evaluating on real traffic (CIC-IDS2017).
